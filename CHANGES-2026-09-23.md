# Catalog changes, Sept 23 2026

These files overlay the full catalog folder (the Drive copy of WEB - CATALOG V2).
Copy them over the same paths there; nothing else in the catalog changed.

New
- js/creatures.js         animal rig engine (clip-and-rotate parts, one shared rAF loop)
- js/creature-shapes.js   path data for 14 animals, cut from animal-sprite-master.svg,
                          chipmunk.svg and fisherman-boat.svg
- js/reference-parts.js   makePine / makeGrass / makeDeciduous / makeSnowfall /
                          makeRainfall / buildBirdFlockCanvas, moved out of the live
                          scene's components.js (the live page never used them)
- assets/animals/*.svg    the 14 isolated animals as standalone SVGs

Changed
- index.html              loads reference-parts.js, creature-shapes.js, creatures.js
- js/catalog-app.js       new kind 'creature' (season / day-night / behavior controls,
                          travel across the card for movers); grid re-render now stops
                          every card's animation loop before discarding it
- js/catalog-data.js      14 Fauna entries, status 'reference'
